工具安装清单

KanaDE2026/5/23大约 1 分钟CTF手册

通用工具

# 系统工具
sudo apt install -y \
    python3 python3-pip \
    git curl wget \
    gdb \
    binwalk foremost \
    wireshark \
    file xxd strings \
    exiftool \
    steghide

# Python 库
pip3 install \
    pwntools \
    requests \
    pycryptodome \
    gmpy2 \
    sympy \
    owiener \
    pillow \
    ROPgadget \
    checksec

Web 方向

工具安装方式用途
Burp Suite官网下载抓包、改包、重放
HackBarFirefox 插件商店快速修改参数
Sqlmappip3 install sqlmap自动化 SQL 注入
Dirsearchpip3 install dirsearch目录扫描
蚁剑（AntSword）GitHubWebShell 管理

逆向方向

工具安装方式用途
IDA Pro自行搜索静态反汇编/反编译
Ghidra官网下载免费替代 IDA
x64dbg官网下载Windows 动态调试
GDB + Pwndbg见下方Linux 动态调试
# 安装 GDB + Pwndbg
sudo apt install gdb -y
git clone https://github.com/pwndbg/pwndbg
cd pwndbg && ./setup.sh

Pwn 方向

pip3 install pwntools ROPgadget checksec

# LibcSearcher（泄露 libc 基址后查版本）
git clone https://github.com/lieanu/LibcSearcher.git
cd LibcSearcher && pip3 install -e .

# glibc-all-in-one（堆题用，可选）
git clone https://github.com/matrix1001/glibc-all-in-one.git

密码学方向

pip3 install pycryptodome gmpy2 sympy owiener

# SageMath（处理格、椭圆曲线等高级数学）
sudo apt install sagemath

在线工具：

  • CyberChef — 编码/解码/加密
  • FactorDB — 大整数分解数据库
  • dCode — 古典密码在线解密

Misc 方向

sudo apt install -y binwalk foremost exiftool steghide wireshark
pip3 install pillow

# zsteg（PNG 隐写检测，需要 Ruby）
sudo apt install ruby
gem install zsteg

Windows 工具：

  • 010 Editor — 十六进制编辑器
  • Audacity — 音频频谱分析
  • Volatility — 内存取证
