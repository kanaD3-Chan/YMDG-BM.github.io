CTF 黑话册

KanaDE2026/8/4大约 8 分钟CTF手册

群里的消息像加密通话？这页把比赛和圈子里常说的黑话收了一遍。不用背，遇到看不懂的回来查就行。顺序大概是从“怎么称呼人”到“比赛里说什么”，再到“技术黑话”“攻防实战”和网上通用语。

黑话在不同圈子意思可能不一样，认准上下文，别在正式场合乱用。

称呼篇

黑话意思用法
大手子东北方言来的网络词，指某个领域特别厉害的人“pwn 大手子”“逆向大手子”，夸人专用
大佬 / 巨佬 / 带佬 / 神佬对高手的敬称，一个比一个夸张大佬最常用，神佬基本是顶配，别乱叫
师傅请教陌生人时用的正经称呼“师傅们，这道题有人看一眼吗”
赛棍常年泡在比赛里的老选手，调侃为主，无褒贬“老赛棍了，什么题没见过”
神仙强到看不懂操作的人“神仙打架”指顶级选手互相卷，围观群众负责喊 666
大腿能带飞你的人“抱大腿”“求带”
萌新 / 菜鸡 / 菜狗 / 小白自称为主真正的大佬也自称萌新，这个头衔别太当真
老司机经验丰富的老手“老司机带带我”
奆佬比巨佬还高一档的称呼，网上流传的战斗力排行是神佬 > 奆佬 > 巨佬 > 大佬 > 萌新 > 咸鱼 > 我碰到真神仙时用，别轻易叫
咸鱼没干劲、躺平的人，自嘲为主“我这条咸鱼先躺了”
卷王拼命刷题、疯狂内卷的人又佩服又害怕的存在
脚本小子只会拿现成工具和脚本、不懂原理的人带点贬义，别当
白帽 / 黑帽合法挖洞、帮忙修漏洞的安全研究者 / 搞破坏的黑客白帽是职业方向，黑帽是刑期方向
嘉豪2025 年火起来的网络梗：穿黑卫衣、戴黑口罩、刻意装神秘、用力过猛的“显眼包”，常见于校园；安全圈也拿它吐槽“低调的黑客”式装酷别当嘉豪
端茶倒水 / 摇扇子表示膜拜，意思是“你太强了”“给大佬端茶倒水”

比赛黑话

黑话意思用法
签到题送分题，基本看一眼就会，用来统计真实参赛人数“开题先做签到”
水题简单、套路常见的题“这周全是水题，AK 了”
阴间题 / 阳间题反人类、脑洞过大的题 / 正常、讲道理的题XCTF 还真有道题叫《真是阳间题》
脑洞题靠联想和知识面，不走常规套路“这题纯脑洞，猜到就秒了”
毒瘤题做起来非常恶心的题常和阴间题连用
一血 / first blood全场第一个解出某道题有的比赛有积分加成，更多是荣誉
二血 / 三血第二、第三个解出某道题的人有的平台会给前三名都加分
上分得分、涨排名“逆风上分”
AKAll Kill，一个方向全解完，或者全场全解完“Web 全 AK”
KOTHKing of the Hill，山大王模式，一群人打同一个目标“KOTH 就看谁守得住”
坐牢 / 卡关长时间解不出来“坐了一下午牢”
自闭 / 破防心态崩了常见于坐牢之后
秒了很快解出来“这题被大佬秒了”
套娃一层套一层，解完一层还有下一层“又是压缩包套娃”
预期解 / 非预期解出题人想好的解法 / 出题人没想到但也能过的解法非预期解不扣分，但写完 wp 最好补上预期解
复现赛后按 wp 把题重做一遍比光看 wp 有用一百倍
考古翻以前比赛的老题来刷考古常见缝合怪
缝合怪把好几个知识点拼在一起出的题“这题缝合了 pwn 和 crypto”
动态积分解出的人越多，题目分值越低所以一血最值钱
加餐 / 加赛比赛中途新放题“主办方又加餐了，估计是看我们太闲”
容器题目的在线环境，一般有时间和并发限制“这题得连容器，别把环境弄崩了”
在线题 / 离线题需要连远程容器做 / 只给附件本地做“离线题留到晚上做”
动态 flag / 静态 flag每队一个专属 flag / 全场同一个 flag动态 flag 专门防抄作业
拼车 / 上车组队 / 加入队伍，从游戏“车队”借来的“还差一个人，拼车吗”
wpwriteup，解题过程记录“赛后看大佬 wp”
expexploit，漏洞利用程序/脚本“exp 跑通了”
出题人题目的制作者常见被迫害对象：“这题是人出的？”
搅屎棍打比赛平台、搞破坏的人正规比赛明确禁止，别学
代打花钱或找人替自己解题正规比赛禁止，别碰
py 交易私下交易、走后门，比赛里指违规搞到 flag 或提示作弊行为，别碰

技术黑话

黑话意思用法
拿 shell / getshell获得目标机器的命令执行权限“进去先拿 shell”
提权从低权限升到 root / admin“拿到 shell 之后提权”
脱壳去掉程序的加壳保护逆向日常
花指令故意插进去的垃圾指令，干扰反编译和静态分析逆向遇到先想办法绕过
堆风水 / 堆喷通过反复分配释放堆块“布置”内存布局 / 大量填充内存提高命中率pwn 堆题里的玄学
爆破暴力枚举密码、密钥、字符“四位数字直接爆破”
弱口令123456、admin 这种一猜就中的密码出题人最爱，先试一遍
越权普通用户访问或操作了管理员的功能Web 经典逻辑漏洞
脱裤 / 拖库把数据库整个偷出来真实世界干这个很刑
撞库拿别处泄露的账号密码去试目标网站真实世界干这个也刑
日站把目标网站打下来圈内常用，语气比较野，别在正式场合说
老巢攻防模式里对方的服务器“把对面老巢端了”
肉鸡被攻击者控制的机器真实世界里拿别人机器当跳板是违法的
跳板中转机器，用来隐藏真实来源渗透里常见
webshell网页后门，通过浏览器操作服务器“上传个 webshell”
免杀让恶意程序绕过杀毒软件“写个免杀马”
社工社会工程学，靠骗不靠攻“这题考社工，去翻他的社交账号”
钓鱼伪装成可信来源骗人上钩注意别点陌生链接
蜜罐故意放出来的诱饵系统，专门钓上钩的攻击者看到“中奖页面”先想想是不是蜜罐
OSINT公开情报搜集“从公开信息挖出坐标”
0day还没公开、没补丁的漏洞很值钱，也很刑
CVE / CNVD国内外漏洞编号库查漏洞先看编号
POC / EXP漏洞证明 / 漏洞利用POC 证明有洞，EXP 把它打成效果
AWD / AWDP攻防 / 攻防加固模式规则详见 CTF 简介与赛道选择

攻防实战

黑话意思用法
红队 / 蓝队 / 紫队攻击方 / 防守方 / 监督裁判方护网和攻防演练里最常听见
护网大型攻防演习，红队打、蓝队防“暑假去护网”
靶机专门拿来练手的有漏洞机器“本地搭个靶机复现”
C2Command & Control，攻击者远程下发指令的服务器“马连上 C2 了”
横移 / 横向移动拿下内网一台机器后，往同网段其他机器扩散“先横移到域控”
权限维持留好后门，保证下次还能进来AWD 里这步做不好等于白打
溯源顺着攻击痕迹查出攻击者蓝队日常：溯源反打

RTFM / STFWread the fucking manual / search the fucking web，翻译过来就是“先看文档”和“先自己搜”
FYIfor your information，供你参考
gggood game，输了/完了
tql太强了
yyds永远的神

整活搞点花活，出人意料的操作，比如“出题人又开始整活了”
乱杀实力碾压，见谁杀谁，比如“这队直接乱杀”
菜鸡互啄菜的人之间打得有来有回，自嘲专用
菜是原罪菜就是最大的问题，多用于自嘲，别拿去说别人
欧皇 / 非酋 / 脸黑运气好 / 运气差，爆破出 flag 也能用
