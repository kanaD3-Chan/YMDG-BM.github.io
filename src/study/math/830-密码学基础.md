## 考试信息

- **科目代码 / 名称**：830《密码学基础》，西安邮电大学自命题
- **适用专业**：083900 网络空间安全（学硕，公共课考数学一）；145200 密码（专硕，公共课考数学二）
- **参考书**：范九伦、张雪锋、侯红霞，《新编密码学》，西安电子科技大学出版社（官方大纲指定第一版，另有第二版）
- **大纲版本**：官方大纲这些年基本稳定，考前还是以学校研究生院最新发布为准

::: note 和 CTF 密码学的区别
这里按考研大纲走体系化学习：830 重原理推导、算法构造和计算，CTF 那套攻击技巧（[ctf/05-crypto](../../ctf/05-crypto/)）重实战。考纲里 RSA 攻击、古典密码分析这些点和 CTF 是相通的，可以互相补。
:::

## 官方大纲（按教材章节）

| 章节 | 大纲要求 |
|------|----------|
| 第 1 章 绪论 | 密码学发展历程（了解）；保密通信模型（掌握）；基本概念（掌握） |
| 第 2 章 基础知识 | 数论基础（熟练掌握）；常用计算复杂性问题（理解） |
| 第 3 章 古典密码 | 常见古典密码加解密原理（掌握）；密码分析技术（掌握）；安全性准则（了解） |
| 第 4 章 分组密码 | 设计准则（理解）；DES、AES、IDEA 加解密与密钥生成（熟练掌握）；RC5（了解）；常用工作模式（掌握） |
| 第 5 章 序列密码 | 基本原理（掌握）；反馈移位寄存器构造（掌握）；常见密钥流生成器（掌握）；常见攻击（了解）；RC4、A5 原理（理解） |
| 第 6 章 Hash 函数 | 概念（掌握）；迭代构造（了解）；MD5、SHA-1 构造原理（熟练掌握）；消息认证码（了解）；HMAC（理解） |
| 第 7 章 公钥密码 | 基本思想与构造要求（掌握）；RSA 加解密（熟练掌握）、常见攻击与防范（理解）、参数选择（掌握）；ElGamal 加解密（熟练掌握）与安全性；有限域椭圆曲线定义性质（熟练掌握）；ECC 特性（了解）；IBE 与 Boneh-Franklin 体制（理解）；公钥应用（了解） |
| 第 8 章 数字签名与身份认证 | 基本原理（熟练掌握）；RSA、ElGamal、DSS 签名（熟练掌握）；特殊签名（了解）；身份认证协议（掌握） |
| 第 9 章 密钥管理 | 密钥管理重要性（了解）；单钥体制密钥管理（掌握）；公钥体制密钥管理（掌握）；Shamir 秘密共享（熟练掌握） |
| 第 10 章 现代密码学发展前沿及应用 | 前沿密码技术发展现状（了解）；应用现状（了解） |

## 复习优先级

大纲里的要求分四档，按这个优先级分配时间：

1. **熟练掌握**：RSA、ElGamal、DES/AES/IDEA、MD5/SHA-1、Shamir 秘密共享、数论基础、数字签名
2. **掌握**：保密通信模型、古典密码、分组密码工作模式、序列密码、密钥管理、身份认证协议
3. **理解**：计算复杂性、RSA 攻击与防范、RC4/A5、HMAC、IBE、ElGamal 安全性
4. **了解**：发展历程、安全性准则、RC5、前沿技术

计算题重点盯这几类：RSA/ElGamal/ECC 的加解密计算、DES/AES 密钥生成、古典密码分析、Shamir 秘密共享恢复秘密。
