这个分区规划了两块内容：**数学一备考笔记**（高数、线代、概率论）和**密码学笔记**（西安邮电大学 830《密码学基础》自命题备考）。

前者跟着备考节奏慢慢填，公式尽量写清楚来龙去脉，而不是直接甩结论；后者按西邮 830 官方大纲整理，参考教材是范九伦等《新编密码学》，把每个考点的原理、算法构造和计算推导写扎实。大纲和章节结构见 [830 密码学基础](./830-密码学基础)，CTF 里的实战打法在 [CTF 密码学章节](../../ctf/05-crypto/)，两边互补着看。
