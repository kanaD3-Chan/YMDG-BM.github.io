数据结构和算法，说白了就是“怎么组织数据、怎么高效处理数据”。数组、链表、栈、队列、树、图，每种结构都有自己的脾气；选对了，代码跑得快还写得爽。

章节顺序：

- [第零章：准备与算法基础](./chapter-0/) —— 环境配置、算法复杂度
- [第一章：线性表](./chapter-1/) —— 顺序表、链表、学生表实战
- [第二章：栈与队列](./chapter-2/) —— 泛型栈、队列、双栈队列与迷宫
- [第三章：树与二叉树](./chapter-3/) —— 二叉树、四种遍历、哈夫曼树
- [第四章：图](./chapter-4/) —— 邻接矩阵/邻接表、DFS/BFS、Prim
- [第五章：查找与排序](./chapter-5/) —— 顺序/折半查找、二叉排序树

::: important
数据结构部分使用的语言为 C/C++，跟着敲一遍比只看不写强得多。
:::
