栈是“后来者居上”，队列是“先来后到”。这一章先用链表实现一个泛型栈，再用两个栈拼出队列，最后拿它们解决报数问题和迷宫搜索。

栈和队列看着简单，却是 DFS/BFS、表达式求值、函数调用栈这些后面内容的地基，值得亲手敲一遍。
