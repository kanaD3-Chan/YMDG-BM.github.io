线性结构是一条道走到黑，树开始有了分岔。二叉树是后面一切树结构（BST、堆、哈夫曼树）的底子，递归在这一章彻底成为主角。

这一章包括二叉树的基本操作与四种遍历，以及哈夫曼树的构造与编码，内容整理自数据结构课程实验。
