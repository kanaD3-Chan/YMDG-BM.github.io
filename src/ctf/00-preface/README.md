这本手册不是教科书。

它是 SLsec 实验室的学长们把自己踩过的坑、走过的弯路整理出来的东西。你不需要有任何基础，但你需要有耐心——CTF 没有捷径，只有一道题一道题地啃。

本章有两篇文章，建议在开始学任何技术内容之前先读完。读完这两篇后，01 通用基础建议先过一遍，02 到 07 的方向章节按兴趣挑着读就行——不用按顺序全刷，CTF 本来就是团队运动，专精一两个方向就够了。

**关于实验室和手册**：你在哪里，这本手册能带你去哪里，以及配套的练习资源在哪里找。

**学习方法**：遇到问题怎么办、怎么用好 AI、怎么提问——这些习惯比任何技术知识都更重要。完整版见分区根目录的 [在第一步之前......](../before-begin) 与 [第一步......](../first-step)。

**免责声明**：认真的。

::: tip
如果你对电脑的认知仅限于下载和玩游戏，请先读 [你缺失的那门计算机课](https://www.criwits.top/missing/)，再回来。
:::
