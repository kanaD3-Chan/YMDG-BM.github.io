在虚拟战场中寻找隐藏的旗帜，于二进制迷宫破解加密的谜语——CTF（Capture The Flag）是一场没有硝烟的攻防演练，也是安全研究者与极客们的思维试炼场。

本分区由两条主线组成：**《CTF 入门手册》**（从[写在前面](./00-preface/)到 [AI 安全](./07-ai-security/)，外加[附录](./appendix/)，面向零基础系统学习六大方向）与 **Writeup 实战记录**（[./writeup/](./writeup/)，赛题解析、出题笔记与团队经验沉淀）。此外还有 [SLsec 实验室](./about-lab.md) 的介绍与[招新信息](./招新宣传.md)。


# 第一次来？
**如果你是第一次阅读本部分内容，且完全没有 CTF 以及网络安全相关经验的话，我们强烈推荐你先去阅读这两篇文章，再继续阅读其他文章：[1. 在第一步之前......](./before-begin) [2. 第一步......](./first-step)**

**关于本分区**：从零开始的 CTF 入门手册，涵盖 Web、Reverse、Pwn、Crypto、Misc、AI 安全等主流方向。无论你是刚接触安全的新人，还是寻求进阶的选手，都能在这里找到清晰的路径——先读"写在前面"建立学习习惯，再按方向章节逐章深入，最后通过实战 Writeup 检验理解。本分区也记录了 **SLsec 实验室** 的日常训练与参赛经验，将团队积累转化为可复用的知识资产。
